# Steinteppich-Balkon-wasserdicht
Ein Steinteppich ist eine moderne Lösung für Balkone, Terrassen und Treppen. Erfahren Sie, worauf es bei der Materialauswahl, fachgerechten Verlegung, Balkonabdichtung und Entwässerung ankommt, um Feuchtigkeitsproblemen vorzubeugen und einen langlebigen Bodenbelag zu planen.
